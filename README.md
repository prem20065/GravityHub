# GravityHub

A premium full-stack student productivity platform built with **React**, **Flask**, and **Firebase**.

## Features
- **Clean Landing Page**: Modern design with Framer Motion animations.
- **Student Dashboard**: Centralized hub for academic life.
- **Task Manager**: Add, edit, and keep track of your tasks.
- **Focus Timer**: Pomodoro-style timer with session tracking.
- **Notes Section**: Auto-saving markdown-friendly notes.
- **Analytics**: Visual progress tracking with interactive charts.
- **Dark Mode**: Sleek glassmorphism-based UI.

## Tech Stack
- **Frontend**: React (Vite), Framer Motion, Lucide Icons, Recharts.
- **Backend**: Flask (Python), CORS.
- **Database/Auth**: Firebase Firestore & Authentication.

## Getting Started

### 1. Prerequisites
- Node.js (v16+)
- Python (3.10+)

### 2. Backend Setup
```bash
cd backend
pip install -r requirements.txt
python app.py
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

### 4. Firebase Configuration
Update `frontend/src/firebase.js` with your Firebase project credentials.
